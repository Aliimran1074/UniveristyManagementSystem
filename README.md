# 🤖 SaaS Learning Management System with Agentic AI

A modern **AI-powered Learning Management System (LMS)** built to help educational institutes manage students, teachers, courses, subscriptions, and AI-powered learning automation.

The system provides multiple user roles with dedicated dashboards and integrates Agentic AI features to automate academic tasks like assignment generation, quiz creation, and evaluation.

# 🧠 Agentic AI Features

The system includes AI agents designed for educational automation.

### ✨ Assignment Generator

Automatically generates assignments from given topics using AI.

Features:

- Topic based generation
- Difficulty selection
- Question count control
- PDF generation


---

### ✨ Quiz Generator

Creates AI-powered quizzes.

Features:

- MCQ generation
- Difficulty control
- Topic based quizzes


---

### ✨ AI Assignment Checker

Automatically evaluates submitted assignments.


---

### ✨ AI Quiz Checker

Checks quiz responses and provides evaluation.
